# Status and testing

Latest retained table: v7. The project has substantial user testing, but not every timer/challenge feature has been confirmed.

- Infinite Health: user-confirmed.
- Freeze Enemies and damage cheats: user reported working. Gadget variants should be tested separately; do not infer support for every gadget.
- Save Position / Teleport / Undo: user-confirmed. J/K/L were requested for these actions.
- Extra-long reach: partial user testing; verify grapple and Batarang cases independently.
- Teleport Up: F1/F2/F3/F4 were requested for the four height options.
- Super Damage and One-Hit: main-keyboard - and = were requested, not keypad keys.
- Challenge/story timers and scores: require further gameplay validation, including whether edited scores actually affect results/medals.

## Removed features

No Hit Detection behaved more like damage prevention and was removed at the user's request. Fly Mode did not work and was removed. Combo, XP, upgrade points, and proposed waypoint teleport were also removed by request. Their presence in old versions is not evidence they are part of the retained design.

## Environmental scan issue

The user could not scan a portrait. Diagnosis involved repeated clean comparisons and an environmental-analysis repair action in the later table. The user ultimately reported LB worked. Do not describe the cheats as a conclusively established cause of the scan problem: the available conversation evidence does not establish that.

A separate crash was reported; no confirmed root cause is documented here. If it recurs, capture game/table version, active scripts, scene, and a clean no-cheat comparison.
