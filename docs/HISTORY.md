# Development history

- v1-v3: initial survival, damage, reach, movement/teleport, and broader requested features; iterative testing.
- Later revisions: removed nonworking/unwanted hit-detection, flight, combo, XP/points, and waypoint ideas; added requested teleport and damage hotkeys.
- Latest revisions: environmental scan investigation and a manual repair option. The user eventually confirmed scanning with LB.

All seven surviving original table versions are retained. Detailed per-version behavior should be read from their scripts and catalogs; this summary does not invent a precise edit-to-version mapping absent supporting records. Available Python research helpers are preserved, but a complete standalone table-generation pipeline was not recovered.
